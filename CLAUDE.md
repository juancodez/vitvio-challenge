# Bit.Bio — Design Project Brief

## Project
**Bit.Bio** is a biotech/life-sciences product design project. Goal: build a clickable prototype ready for stakeholder review by next week.

## Stack
- Design tool: Figma
- Prototype: Figma interactive prototype
- Tokens: `design-tokens.json` (single source of truth)
- Components: `src/components/` (HTML/CSS reference implementations)

## Brand
- Voice: precise, scientific, trustworthy — never cold
- Visual direction: clean white-space, structured grids, subtle biological/organic accent shapes
- Primary color: see `design-tokens.json` → `color.brand.primary`
